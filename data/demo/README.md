# NidaanKosha Cardiometabolic Demo Sample

## File Information
- **File**: `labs_cardiometabolic_sample.parquet`
- **Source**: Derived from [NidaanKosha-100k-V1.0](https://huggingface.co/datasets/ekacare/NidaanKosha-100k-V1.0) by Eka Care & IndiaAI.
- **Record Count**: 25,000 cardiometabolic lab investigation readings (sampled with fixed seed `42`).
- **File Size**: ~0.88 MB (under 5 MB limit).
- **Columns**: Identical schema to original dataset:
  `['document_id', 'age', 'gender', 'test_name', 'display_ranges', 'value', 'unit', 'specimen', 'loinc']`
